## 二、 关键数据流与 RPC 调用闭环

1. **wbfarm / 爬虫节点捕获人机挑战**：
   - 提取目标验证码 Base64 图片与背景切片；
   - 附带题目类型枚举（`click_text`, `slide_distance`, `rotate_angle`）。
2. **打码请求分发**：
   - 通过 HTTP POST 调用 `http://156.225.28.208:8766/recognize`（五四云-1030A）；
   - 若 1030A 响应耗时 > 1500ms 或返回连接拒绝，自动秒级重试降级至五四云-1030B。
3. **坐标反算与拟人轨迹回填**：
   - 打码节点返回精准物理像素坐标 `(x, y)`；
   - 爬虫使用贝塞尔曲线轨迹（Bezier Curve）派发鼠标拖拽事件，杜绝被行为反爬识别。

## 三、 历史核心死穴与刚性防御不变量 (Anti-Bug Invariants)

1. **[INV-CAPTCHA-01] 动态链接库多平台崩溃死穴**：
   - 历史痛点：`HPSocket4C.dll`、`WM.dll` 为 Windows 32/64 位原生二进制库，直接复制到 Linux 机器必然报错 `cannot execute binary file`。
   - 刚性防御：**Linux 云服务器一律运行 Python ONNXRuntime / Torch 纯净推理容器**，彻底解耦对 Windows C++ DLL 的硬依赖。
2. **[INV-CAPTCHA-02] 逆向补丁版本失配死穴**：
   - 历史痛点：WorkBuddy 客户端更新导致 ASAR 哈希变更，旧补丁强制覆盖导致客户端白屏崩溃。
   - 刚性防御：`_asar_probe.js` 必须在解包前核验 ASAR SHA-256，非目标版本自动安全终止，严禁盲改。
3. **[INV-CAPTCHA-03] 打码超时导致的 Worker 级联阻塞**：
   - 刚性防御：打码请求必须设置硬超时（`timeout=3.5s`），超时立即换 IP 刷新验证码，严禁 Worker 挂起等待超过 5 秒。

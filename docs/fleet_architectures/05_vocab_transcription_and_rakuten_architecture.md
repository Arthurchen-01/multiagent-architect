# 🗣️ 词汇转写 (Vocab) 与乐天高频采集矩阵多服务器架构表

> **业务定位**：语音转写站（MP3 自动转录为 DOCX 学习文档）+ 跨境电商乐天（Rakuten）多节点分布式采集与价格监控矩阵。

---

## 一、 跨机分片与资源隔离拓扑

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 词汇站与语音转写中心 (五四云-1021: 16C16G+200G)                     │

```

## 二、 关键性能与防 OOM 隔离机制

1. **CPU 密集型 ASR 转写与爬虫严格隔离**：
   - 语音转写模型加载会消耗 4~8GB 显存/内存及多核 CPU；
   - 在 `systemd` 配置中针对 `vocab-asr-worker` 施加 cgroups 资源限制：
     ```ini
     [Service]
     CPUQuota=800%
     MemoryMax=10G
     Nice=10
     ```
   - 避免语音转写瞬时峰值压垮同节点的乐天实时采集进程。
2. **乐天分布式分片防频控封锁**：
   - 7 个采集分片按店铺 ID 模除（`shop_id % num_shards`）实现物理分片；
   - 各分片携带独立隧道代理出口，并对目标接口执行指数退避重试（Backoff + Jitter），彻底消除单 IP 请求过载封禁。
